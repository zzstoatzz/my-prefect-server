## Method

```sh
fly apps list --json
fly machines list -a APP --json
fly volumes list -a APP --json
curl -s https://hub.waow.tech/api/costs.json   # provider "fly", service prefix = app
grep -rl --include='fly*.toml' -E '^app *= *' ~/tangled.org ~/github.com
```
